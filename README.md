# Рекомендательная система мер воздействия для должников — ЭнергоХак 2026

Решение кейса хакатона «ЭнергоХак» (заказчик — ПАО «ТНС энерго Ярославль», апрель 2026, **3 место**): система определяет оптимальные меры воздействия на абонентов — физических лиц с задолженностью за электрическую энергию.

## Задача

Энергосбытовая компания ежемесячно формирует список абонентов с просроченной задолженностью и ограниченным набором мер воздействия (СМС, обзвон оператором, e-mail, претензия, выезд, ограничение потребления и т. д.), при этом на каждую меру действуют месячные лимиты. Требуется для каждого должника подобрать меры так, чтобы максимизировать ожидаемый возврат долга в рамках лимитов, и уметь объяснить рекомендацию бизнесу.

## Как устроено решение

1. **Данные и признаки.** 14 выгрузок (профиль лицевого счёта, оборотно-сальдовая ведомость, оплаты, история мер воздействия) → конструирование признаков профиля, платёжного поведения и реакции на прошлые меры (`feature_engineering.py`, `build_training_dataset.py`, `convert_xlsx.py`).
2. **Сегментация.** Кластеризация должников по профилю и платёжному поведению (`clustering.py`, `clusters_info.py`).
3. **Прогноз возврата.** Регрессионная модель LightGBM предсказывает ожидаемую сумму снижения долга для каждой допустимой меры (`train_model.py`).
4. **Назначение мер.** Жадный алгоритм распределяет меры по абонентам с учётом месячных лимитов, максимизируя суммарный ожидаемый возврат (`recommend.py`).
5. **Объяснимость.** SHAP-анализ: какие факторы повлияли на рекомендацию по конкретному лицевому счёту (`explain.py`), сводный отчёт (`report.py`).
6. **Интерфейс.** CLI (`run.py`) и GUI (`gui.py`).

## Запуск

```bash
pip install -r requirements.txt

python run.py --mode train    # сборка обучающего датасета и обучение модели
python run.py --mode infer    # рекомендации на целевой месяц
python explain.py 123456      # объяснение рекомендации по лицевому счёту
python run.py --mode report   # сводный отчёт
```

## Данные

Данные хакатона (персональные данные абонентов) в репозиторий **не входят**. Положите выгрузки (01–14, Excel/CSV) в каталог `data/` — конвертация и сборка датасета выполняются автоматически.

## Стек

Python 3.13+, pandas, numpy, LightGBM, scikit-learn, SHAP, openpyxl.
